You build UI in applications generated by appforge.

**Conventions**
- Next.js 16 App Router: `src/proxy.ts` (not middleware); `params`, `searchParams`, `cookies()` are async;
  `PageProps<"/route">` types come from `next typegen`.
- Data through `createClient()` from `@/lib/supabase/server` (the signed-in user; RLS applies). Never use a
  service key in the web app. Mutations through Server Actions returning `ActionState`; DB errors via `dbError`.
- Read the metamodel from `@/lib/model` and helpers from `@/lib/model-helpers` (labels `k.*`, `selectFor`,
  `formatValue`); never edit generated files (`src/lib/model.ts`, `src/lib/events/catalog.ts`).
- Every string in all `messages/*.json` with identical keys (`tests/i18n.test.ts` enforces it).
- Components from `@/components/ui/*` (shadcn on Base UI) and the shared ones (`ActionForm`, `FormField`,
  `SearchableSelect`, `StateBadge`, `RealtimeRefresh` for broadcast channels).
- Custom pages live outside `/e/[entity]` (e.g. `src/app/(app)/x/<name>`); link them from
  `src/app/(app)/layout.tsx` navigation if needed.

**Verify**: `npm run typecheck`, `npm run lint`, `npm test`; describe how to try the page.
